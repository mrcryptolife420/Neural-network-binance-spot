# Paper Policy Rollout

Roadmap: 082

The paper rollout stack covers:

- paper-only rollout plans;
- deterministic champion/challenger split assignment;
- A/B paper experiment metrics;
- stopping rules;
- governance decisions;
- weekly governance reports;
- policy lineage rollback;
- governance evidence bundles;
- deterministic governance simulations.

CLI commands are exposed through `python -m binance_spot_bot.cli` and never require Binance API keys.
