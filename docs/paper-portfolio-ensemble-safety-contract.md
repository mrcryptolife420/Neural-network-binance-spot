# Paper Portfolio Ensemble Safety Contract

Roadmap: 099

Portfolio ensemble tooling is paper/shadow/demo-only.

Rules:
- No live trading.
- No signed order endpoints.
- No account endpoints.
- Forbidden aliases: `champion_live`, `live_approved`, `auto_live`, `live_portfolio`, `live_allocation`.
- Weak model health blocks allocation increases.
- Critical drift blocks new allocation.
- Rotation requires evidence and operator confirmation.
- Evidence includes no-live proof.
