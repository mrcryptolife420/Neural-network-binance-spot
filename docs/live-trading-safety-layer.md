# Live Trading Safety Layer

Roadmaps: 118-121

The live trading layer added here is safety-first and non-submitting by default. It supports read-only account dry-run checks, order preview hashing, micro-session planning, automatic disarm rules, session review, scorecards, execution quality analytics, risk calibration proposals, scaling governance, operator approval, profile lifecycle guards, regression checks, incident response, and post-trade forensics.

Tests assert that no live order is submitted and signed order endpoints are not called.
