# Windows 11 Dashboard V2 Start

Use `Start-Neural-Binance-Bot.cmd` from the repository root. It sets safe environment defaults, uses `.venv\Scripts\python.exe` when available, then starts Dashboard V2 through the CLI launcher report.

If Python 3.12 is not installed, use the existing `.venv` or create a venv with the installed Python version:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```
