# Weekly Governance Report

The weekly governance report writes local evidence in multiple formats:

- `weekly_governance_report.json`
- `weekly_governance_report.md`
- `policy_status.csv`
- `experiment_results.csv`
- `governance_decisions.jsonl`
- `evidence_manifest.json`

Reports are redacted and paper-only. They summarize the current champion, experiments, decisions, and evidence file inventory.
