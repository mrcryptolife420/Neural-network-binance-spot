# Walk-Forward Robustness Safety Contract

Allocation Robustness Lab is local paper research only.

- No live mode is allowed.
- No signed, account or order endpoints are used.
- API keys are not required.
- Rolling simulations require `RUN_WALK_FORWARD_PAPER_RESEARCH_ONLY`.
- Split boundaries are required before out-of-sample robustness claims.
- Reports must include `live_trading_enabled=false`.
- Evidence must include no-live, no-real-allocation and no-advice proof.
