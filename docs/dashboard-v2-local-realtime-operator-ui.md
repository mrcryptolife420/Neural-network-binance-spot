# Dashboard V2 Local Realtime Operator UI

Roadmaps: 104-111

Dashboard V2 surfaces are local and refresh-free by contract: backend-managed state, websocket-style events, parity checks, packaging plans, operator workflow groups, Streamlit deprecation planning, advanced panel layouts, and pluginless extension packs.

The implementation is intentionally local-first and does not replace the existing Streamlit runtime until parity, smoke tests, and rollback evidence are present.
