# Workspace API

Dashboard V2 exposes local workspace routes:

- `GET /api/workspaces`
- `POST /api/workspaces`
- `GET /api/workspaces/{workspace_id}`
- `POST /api/workspaces/{workspace_id}/clone`
- `POST /api/workspaces/{workspace_id}/export`
- `DELETE /api/workspaces/{workspace_id}`
- `GET /api/workspace-presets`
- `GET /api/widgets`
- `GET /api/analytics/query`
- `GET /api/watchlists`
- `GET /api/preferences`

Responses include `live_trading_enabled=false`.
