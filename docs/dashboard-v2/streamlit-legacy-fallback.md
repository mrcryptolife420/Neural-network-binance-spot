# Streamlit Legacy Fallback

Dashboard V2 is the recommended realtime UI, but Streamlit remains available.

- `python -m binance_spot_bot.cli dashboard --v2` prints the V2 launch plan.
- `python -m binance_spot_bot.cli dashboard --legacy-streamlit` keeps the Streamlit command path.
- `python -m binance_spot_bot.cli dashboard-legacy --json` reports fallback status.
