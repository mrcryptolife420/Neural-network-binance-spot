# Live Scaling Governance Safety Contract

Live scaling never happens automatically.

Rules:

- No profile promotion without live session evidence.
- No risk-limit increase without explicit operator approval.
- No promotion with unresolved P0/P1 findings, reconciliation mismatch, emergency stop, excessive slippage/spread/fees, session loss breach, or evidence hash failure.
- Approval must be timestamped, auditable, redacted, one-time, and explicit.
- Demotion, rollback, blocking, and expiration remain available.
- Governance routes never place orders and never start live sessions.
