# Scanner Widgets

Roadmap 112 adds Dashboard V2 widget types for local scanner workspaces:

- `market_scanner_health`
- `public_endpoint_policy`
- `rate_limit_budget`
- `symbol_universe`
- `watchlist_snapshot`
- `market_ranking_table`
- `spread_volume_matrix`
- `volatility_momentum`
- `data_freshness`
- `market_data_quality`
- `symbol_detail`
- `multi_symbol_paper_analytics`
- `scanner_evidence`

All widgets are secret-safe and scoped to demo, paper, and testnet-readiness modes.
