# Demo-to-Live Evidence

The evidence bundle links demo targets, vault manifests, quality reports, feature/label data, split governance, model validation, paper replay, testnet promotion, testnet rehearsal, and live candidate blockers.

Evidence requirements:

- secret-free
- hashed manifest
- no-live-order proof
- no-financial-advice proof
- live execution remains blocked

Use:

```powershell
python -m binance_spot_bot.cli demo-to-live-evidence-export --json
```
