# Local AI Ops Assistant Safety Contract

The AI/Ops assistant is advisory and read-only. It may summarize redacted local artifacts, classify safe operator questions, recommend runbooks, and propose allowlisted commands.

It must not reveal secrets, enable live trading, place or cancel orders, query real accounts, upload data remotely, bypass risk controls, or execute commands automatically.

Rules-only mode is the default. Remote LLM mode is blocked by default.
