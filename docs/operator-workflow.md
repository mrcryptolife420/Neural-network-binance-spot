# Operator workflow

Status: local paper/testnet-readiness only. Live trading remains disabled.

1. Start the dashboard with `Start Bot Dashboard.cmd`.
2. Confirm the header shows `Live: disabled`.
3. Run Local Demo first.
4. Inspect Strategy Lab for signal and risk-block explanations.
5. Use Demo Spot Trading only for local paper fills.
6. Run a paper session from CLI when you want a report bundle.
7. Open Sessions to replay or compare runs.
8. Open Readiness to see evidence blockers and next safe steps.
9. Create a backup or support bundle before large changes.

No step requires real API keys. Binance Demo/Testnet keys are optional readiness inputs and must stay session-only unless a later secure storage flow is explicitly used.
