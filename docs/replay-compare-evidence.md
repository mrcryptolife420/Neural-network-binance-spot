# Replay, compare and evidence

After a run, use the Sessions tab to replay snapshots and compare 2-10 sessions.

The evidence flow records hashes for local artifacts such as:

- `check-all` output;
- session report summaries;
- shadow/no-signed-endpoint proof;
- readiness score.

Readiness can show progress but cannot enable live trading. The score keeps `live_allowed=false` until a future manually reviewed live pilot is designed outside the dashboard execution path.
